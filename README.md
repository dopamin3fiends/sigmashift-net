# sigmashift-net

Source for [sigmashift.net](https://sigmashift.net), the company site for SigmaShift, served from `main` via GitHub Pages.

SigmaShift builds AI-powered software products:

- **SponsorshipEngine** (`sponsorship-engine.html`): sponsor discovery and outreach software for events, tours and talent managers.
- **Elephant in the Room** (`elephant-in-the-room.html`): AI-powered dispute mediation for personal, workplace and family conflicts.

Legal pages: `terms.html`, `privacy.html`, `refunds.html`. Contact: support@sigmashift.net

Static site, no build step. `robots.txt` and `sitemap.xml` are maintained by hand.
