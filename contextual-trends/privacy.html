Contextual Trends Publisher ("the tool") is a private publishing tool operated by Kurt Carrington Warner ("I", "me") for my own YouTube channels. This policy explains what data the tool uses, why, and how you can remove its access.

YouTube API Services

The tool uses YouTube API Services, including the YouTube Data API and the YouTube Analytics API. By using the tool you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Who uses the tool

The tool is not offered to the public. The only user is the channel owner, who signs in with their own Google account. It acts only on YouTube channels owned by that account.

What data the tool accesses

With the signed-in owner's permission (Google OAuth), the tool accesses:

  • Channel and video information for the owner's own channels: channel ID and name, video IDs, titles, descriptions, upload status and publish times.
  • Statistics for the owner's own videos: views, watch time, retention, impressions, click-through rate and subscriber changes (YouTube Analytics API).
  • Comments on the owner's own videos, so the owner can read and reply to them.
  • OAuth tokens that Google issues so the tool can act on the owner's behalf.

The tool also uploads the owner's own video files, thumbnails and metadata to YouTube.

How the data is used

  • To upload and schedule the owner's videos and Shorts.
  • To show the owner which of their videos perform best, so they can plan future videos.
  • To let the owner reply to comments on their own videos.

The data is not sold, rented, shared with third parties, used for advertising, or used to build profiles of viewers.

How the data is stored

Everything the tool keeps is stored only on the owner's own computer, in a local database. Nothing is sent to any server operated by me. OAuth tokens are stored locally and used only to call Google's APIs. Video titles, descriptions and comment text retrieved from YouTube are refreshed or deleted within 30 days, as YouTube's developer policies require. Statistics for the owner's own videos may be kept for up to 36 months to compare performance over time.

Cookies and tracking

The tool does not use cookies, analytics or tracking of any kind. This website does not either.

How to revoke access and delete data

  • You can remove the tool's access to your Google account at any time from the Google security settings page.
  • When access is revoked, the tool can no longer call YouTube on your behalf. To have all stored data deleted, email the address below and it will be deleted within 7 days. Stored data is also deleted within 30 days of access being revoked.

Changes

If this policy changes, the new version will be posted on this page with a new "last updated" date.
